# Font Duel Investigator

Crie o objeto digital interativo “Duelo das Fontes — Antes de acreditar, investigue!” exatamente conforme o PRD fornecido pelo usuário. Implemente arquitetura completa, todas as telas, conteúdo literal, mecânicas, navegação controlada, feedbacks contextuais, Painel de Investigação, três duelos e Kit do Investigador. Prioridade absoluta para desktop 1200×675 sem scroll nas telas principais e responsividade em telas menores. Use somente placeholders claramente identificados para Maya e demais assets definitivos, sem SVG/CSS/emoji/personagens externos; organize caminhos estáveis em /public/assets/personagens/, /fundos/, /interface/, /fontes/ e /audio/. Examine o ZIP anexado: se contiver assets que possam ser usados sem contrariar o PRD, organize-os nos caminhos previstos, sem renomear posteriormente; não crie ilustrações substitutas. Prepare áudio com botões visuais e estrutura para MP3. Respeite a pedagogia: não tratar fontes como verdade/falso nem boas/ruins, não pontuar, sem cores que antecipem resposta, sem feedback “errado” ou “tente novamente”. Preserve os textos e progressão do PRD. Garanta acessibilidade completa, estados teclado/focus, alt/labels. Habilite Lovable Cloud se for necessário para a solução, mas esta experiência pode funcionar localmente sem persistência. Faça build e verifique o funcionamento.
